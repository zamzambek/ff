# KAINAP motion: обучающие вертикальные ролики из кода

Ролик собирается из HTML-сцены, привязанной к озвучке. Готовый файл: MP4 1080×1920, 30 fps.

```
video/
  build.sh                    полная сборка: озвучка → кадры → звук → mp4
  engine/engine.js, style.css общий движок и стиль кадра (токены цветов в :root)
  assets/fonts/               Nunito (OFL), включая ң ө ү
  tools/tts.py                озвучка (запись диктора или espeak-ng) + тайминги слов
  tools/render.js             покадровый рендер через Playwright → ffmpeg
  tools/mix.py                голос + «попы»/«вжухи» (+ музыка по желанию)
  projects/co-vs-co2/
    script.json               текст по фразам (show — субтитр/диктор, say — для синтезатора)
    scene.html                сцены и анимации
    voice/                    СЮДА кладутся записи диктора: s1.wav, s2.m4a, …
    build/                    результаты (в git не попадают)
```

## Запуск

```bash
apt-get install -y espeak-ng      # только если нет своих записей голоса
cd video
./build.sh projects/co-vs-co2     # ~3 мин → projects/co-vs-co2/build/co-vs-co2.mp4
./build.sh projects/co-vs-co2 --music путь/к/треку.mp3   # с фоновой музыкой (только лицензионной)
```

Быстрая проверка без полного рендера:
```bash
node tools/render.js projects/co-vs-co2 --stills 3,20,55 --scale 0.5   # стоп-кадры в build/stills
```
Предпросмотр в браузере со звуком: открыть `projects/co-vs-co2/scene.html?play` и кликнуть.
Отдельный кадр: `scene.html?t=12.5`.

## Своя озвучка (рекомендуется)

Синтезатор espeak-ng звучит как робот, его голос нужен только для черновика и таймингов. Для публикации:
1. Запиши каждую фразу из `script.json` (поле `show`) отдельным файлом: `voice/s1.m4a` … `voice/s20.m4a`.
   Подойдёт диктофон iPhone; тишину по краям скрипт обрежет сам, громкость выровняет.
2. Запусти `./build.sh projects/co-vs-co2`. Анимация и субтитры подстроятся под твой темп.
   Можно записать только часть фраз, остальные возьмутся из синтезатора.

### Нейроозвучка ElevenLabs

1. Ключ API подключается к окружению через защищённую форму (хост `api.elevenlabs.io`, заголовок `xi-api-key`).
   В код и в git ключ не попадает.
2. Выбрать голос: `python3 tools/elevenlabs.py voices`, затем вписать его id в `script.json`:
   ```json
   "tts": { "provider": "elevenlabs", "voice_id": "…", "model_id": "eleven_v3", "language_code": "ky" }
   ```
3. `./build.sh projects/<тема>`. Каждая фраза озвучивается отдельно, тайминги слов точные.
   Ответы кешируются в `build/el-cache`, поэтому повторная сборка кредиты не тратит.
   Если в `voice/` лежат записи диктора, они важнее ElevenLabs.

### Один дубль вместо 20 файлов

Можно записать весь текст подряд одним файлом `voice/take.m4a`. Скрипт найдёт слоги в записи
и разложит по ним слова текста. Важно: читать **точно по `script.json`**, иначе субтитры разойдутся с голосом.
Паузы около секунды между фразами повышают точность. Записи голоса в git не попадают.

## Как сделать новый ролик

1. Скопируй `projects/co-vs-co2` в `projects/<тема>`, удали `build/` и `voice/`.
2. В `script.json` напиши текст по фразам (одна фраза ≈ одна мысль, 3–8 секунд).
3. Запусти `python3 tools/tts.py projects/<тема>`, чтобы получить тайминги.
4. В `scene.html` опиши сцены. Каждый элемент появляется на нужном слове:
   `data-in="s6#3"` (4-е слово фразы s6, счёт с нуля). Остальные атрибуты описаны в начале `engine/engine.js`.
5. Проверь стоп-кадрами и собери видео через `build.sh`.

## Стиль «силуэт-притча» (16:9)

- `engine/people.js` — стройные силуэты с суставами (плечо/локоть, бедро/колено), походка и позы:
  `stand phone reach chest hold lookup down sit read sitphone sithold`.
- `engine/fx.js` — дождь, пар, огонь, ночной город, боке, светящееся сердце.
- В `engine.js`: камера `data-cam`, растворения сцен `<body data-xfade>`, пульс `data-beat`,
  цветные слова в субтитрах: `*золото*`, `~синий~`, `^красный^`.
- Концовка: `tools/append_outro.sh <ролик> <секунда> <выход> projects/outro4/build/outro4.mp4`.

## Ограничения

- Логотип: `assets/brand/kainap-logo.png` (вырезан из присланного JPG). Фирменный синий `#3A3CF4` в `engine/style.css`.
- Тайминги слов внутри фразы примерные (по длине слов). Начало каждой фразы точное.
- Иконки берутся из шрифта Noto Color Emoji. На другой машине он должен быть установлен.
