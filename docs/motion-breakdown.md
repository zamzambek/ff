# Разбор стиля: обучающий motion-ролик (референс «Реакциянын 4 түрү»)

Референс: вертикальное видео 720×1280, 30 fps, 2:53, озвучка на кыргызском.
Важно: это **чужой ролик**. Берём приём и жанр, а не его оформление, тексты и ник.
У KAINAP свои цвета (после утверждения логотипа), свой маскот и свои темы.

## 1. Из чего состоит кадр (он одинаковый весь ролик)

```
┌──────────────────────────┐
│  [лого] САБАК · ХИМИЯ    │  ← шапка: бренд + тема ролика + ник. Не меняется весь ролик
│  Тема ролика · @ник      │
│      ( плашка раздела )  │  ← «о чём сейчас»: Реакция деген эмне / 1-түрү / Эстен кал
│                          │
│   ОСНОВНОЙ ВИЗУАЛ        │  ← формула / молекула / 3D-иконка / схема A+B→AB
│   + подписи-плашки       │
│                          │
│ ┌──────────────────────┐ │
│ │ субтитр [слово] ...  │ │  ← белая карточка, 2–4 слова, текущее слово на жёлтой плашке
│ └──────────────────────┘ │
│                    [■]   │  ← маскот/стикер в углу, слегка покачивается
└──────────────────────────┘
фон: светло-лавандовый + 3 больших размытых круга (мята, персик, сирень),
мерцающие звёздочки, почти прозрачный водяной знак с ником по всему фону
```

Почему это работает:
- **Шапка не меняется**: зритель всегда понимает, какой это канал и какая тема. Скриншот ролика сам по себе рекламирует канал.
- **Субтитры-караоке**: большинство смотрит Reels без звука. Подсвеченное слово ведёт взгляд и не даёт пролистать.
- **Ни одной склейки.** Детектор сцен не нашёл ни одного резкого перехода за 2:53. Всё строится из появления и исчезновения элементов, поэтому глаз не устаёт.
- **Водяной знак по всему фону** мешает перезаливам. Для закрытого Telegram-канала KAINAP это тоже полезно.

## 3. Правила движения (тайминги)

- **Появление «поп»**: масштаб 30% → 108% → 100% (ease-out-back) за ~0,4 с, прозрачность за первые 0,1 с.
- **Каждый новый элемент появляется ровно на слове**, которое его называет. Это главное правило.
- **Стаггер**: однотипные элементы (① ② ③ ④, атомы) идут с шагом 0,15–0,25 с.
- **Смена темы**: старое уходит вверх с затуханием (~0,3 с), новое выпрыгивает. Склеек нет.
- **Фон всё время дышит**: круги медленно плавают, звёздочки мерцают. Даже на паузе кадр «живой».
- **Подсветка**: часть формулы перекрашивается в акцентный цвет, когда о ней говорят.
- **Звук**: короткий «поп» на каждое появление и мягкий «вжух» при смене блока.

## 4. Рецепт для новых идей KAINAP (шаблон на 60–100 с)

1. **Хук (0–5 с)**: контраст, число или угроза + обещание. «CO жана CO₂: айырмасы бир атом, бирок…»
2. **Ключ к пониманию (5–25 с)**: один инструмент, например как читать формулу.
3. **Ядро (25–70 с)**: 2–4 блока по схеме *шаблон → пример из жизни Кыргызстана → вывод-плашка*.
4. **Практика / польза для жизни**: что делать (печь зимой, лекарства, еда, спорт).
5. **«Өзүңдү текшер»**: вопрос, ответ на который пишут в комментариях.
6. **CTA**: сактап кой / досуңа жөнөт / кайсы тема керек.

Формулы хуков, которые подходят KAINAP:
- «Бир эле ___, бирок ___» (CO/CO₂, H₂O/H₂O₂, алмаз/графит — оба из углерода)
- «ОРТдо эң көп ката кетирилген ___» (без выдуманной статистики, только по реальному разбору ошибок учеников)
- «Эмне үчүн ___?» из быта: почему чернеет яблоко, почему жжёт крапива, почему горит газ на плите синим
- «N түрү / N кадам» со счётчиком

## 5. Как это сделано у нас

См. `video/README.md`. Коротко: кадр — это HTML-страница, анимация — функция от времени `renderAt(t)`,
Playwright делает скриншот каждого кадра, ffmpeg собирает видео. Тайминги берутся из озвучки,
поэтому если перезаписать голос, анимация сама подстроится под новые слова.
