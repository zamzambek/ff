# Стиль «силуэт-притча»: разбор референса и идеи для KAINAP

Референс №3: 1276×718 (16:9), 24 fps, 50 с, русский мужской голос. Это чужой ролик: берём только приём, без текста и сцен.

## 2. Из чего сделана атмосфера
- **Свет:** почти чёрный фон, один тёплый источник (фонарь, лампа, закат) и **один цветовой акцент** (красное сердце / роза). Виньетка, мягкие боке-круги.
- **Персонажи:** чёрные силуэты-стикмены с тонким контровым светом, минимум движения (жест, шаг, сидит).
- **Монтаж:** без резких склеек, плавные затемнения; сцена держится 2,5–5 с, камера медленно наезжает.
- **Текст:** 1–2 строки внизу по центру, белый жирный, 1–2 ключевых слова золотом.
- **Голос:** близкий, разговорный, с вопросами к зрителю («Знаешь почему?») и короткими усмешками.
- **Звук:** непрерывная меланхоличная музыка; дождь только в части сцен, тихо.
- **Структура:** парадокс → вопрос → объяснение → ирония → контрастные пары → второй вопрос → кольцевой финал.

## 3. Правила для KAINAP в этом стиле
- Формат **16:9, 1920×1080**.
- Логотип: маленький белый знак в углу (полупрозрачный) и финальная карточка KAINAP на 2 с.
- Дождь тихо, только там, где нужен по сцене.
- Каждая притча заканчивается **точным фактом из программы** (ЖРТ) — это отличает нас от «просто грустных роликов».
- Никаких обещаний баллов/поступления, никаких выдуманных цифр.
